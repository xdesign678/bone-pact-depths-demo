改造成果（重点）

🎨 视觉：一眼吸血鬼幸存者

原来的游戏用的是 AI 生成的高清素材，这次全部换成了程序绘制的纯像素。

启动画面：纯黑背景 + 像素字体标题 + 极简进度条，没有多余装饰

10 秒时：玩家（紫色像素小人）带着 2 只白色骷髅，地板是棕灰色像素格

30 秒时：3 只召唤物环绕玩家，右上角倒计时 04:52，UI 也是像素风硬边。所有 sprite 边缘都是锐利的像素锯齿，没有抗锯齿模糊。

改了什么：

  • 引擎配置：pixelArt=true, roundPixels=true, antialias=false（抗锯齿关闭，像素对齐开启）
  • PixelArtPack 覆盖 19+ 精灵表：玩家、16 种召唤物、9 种敌人、Boss、地板、墓碑、石柱、血池、召唤圈、灵魂火、投射物
  • 后处理自动降级：像素模式下 bloom（光晕）和 horrorFx（恐怖滤镜）自动关闭，只保留暗角

对你的意义：无论你在手机还是电脑打开，画面都是统一的复古像素风，像在玩 90 年代的掌机，但性能更好。

对你的意义：一局就是 30 分钟，不用换地图、不用读条，专注割草和构筑。每分钟都有正反馈（宝箱），每 5 分钟一个大心跳（Boss）。

Commander 修复的 9 个 P0/P1

子代理写完后，Commander 亲自排查并修复了 9 个较严重问题。如果不管它们，游戏会无法解锁召唤物、技能不生效、甚至启动卡死：

编号 严重度 问题 怎么修的
F-1 🔴 P0 闪电亡魂的链式闪电读取了 scene.enemies，但这个数组永远是空的 改成通过 callback getEnemiesInRange 获取真实敌人列表
F-2 🔴 P0 鬼面虎灵「击杀回血」把数据写进 sprite，但 PlayerSystem 根本不读 改成 callback healPlayer，击杀时直接调用回血函数
F-3 🔴 P0 7 个新技能只改了 GameState 数据，但游戏主循环没消费它们（等于白买了） 在 BonePactSceneCore 新增 instance 字段 + applySurvivorSkills + getSurvivorAttackMultipliers，让 MinionSystem 攻击时真正用上这些 buff
F-4 🔴 P0 腐毒胞囊和棘刺丛的解锁条件是 depthLevel >= 2，但幸存者模式永远锁在 depth=1，等于永远解锁不了 去掉 depthLevel 限制条件
F-5 🔴 P0 美术资源包把 4 个新召唤物也加入预加载列表，但对应的图片文件不存在，导致 Phaser 启动卡死 新增 LEGACY_MASTER_PACK_KINDS 列表，排除 4 个新 kind
F-6 🟡 P1 轨道骨刀 hp=999 但 update 循环里有个清理点会把它删掉，等于不是真不死 在 updateMinions 顶部加判断：如果是 orbitblade 且 hp<=0 就重置为满血
F-7 🟡 P1 布尔型技能（吸血光环/召唤暴走）可以重复选，第二次选完全浪费 在 upgradePool 加 filter：已解锁的布尔技能不再出现
F-8 🟡 P1 冰封大陆「受伤冰冻敌人」没有 hook 进受伤逻辑，买了不生效 把 glacialContinent 完整 hook 进 damagePlayer 流程
F-9 🟡 P1 playtest:full 套件包含 depth 和 savecompat 场景，与幸存者模式不兼容（断言 depth>=2 必失败） 从默认 PLAYTEST_SCENARIOS 中移除这两个场景

对你的意义：这 9 个 bug 如果流入正式版，会出现「买了技能没效果」「新召唤物永远解锁不了」「游戏启动黑屏」等问题。Commander 在合并前全部拦下并修好，相当于最后一道人工 QA。

怎么自己玩

# 1. 安装依赖（如果还没装）
npm install

# 2. 启动开发服务器
npm run dev -- --port 5177

# 3. 浏览器打开
# http://localhost:5177/?pixel=1
# 如果 URL 里不加 ?pixel=1，像素风也会默认开启（qualityProfile 默认 true）

操作指南：

  • 左下角虚拟摇杆（或 WASD）移动
  • 右下角按钮：召回 / 终契 / 献祭 / 聚魂
  • 底部一排是召唤物栏，点击召唤
  • 升级时从 3 张卡片里选 1 张
  • 目标：活过 30 分钟，击败终极 Boss！
